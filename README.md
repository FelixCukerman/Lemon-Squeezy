# LemonSqueezy

Статичний сайт для GitHub Pages. Точка входу: `index.html`.

`css/` — стилі сайту
`js/app/` — власні JavaScript-модулі
`js/config/` — конфігурація Firebase
`js/data/` — даммі дата, довідники та мапінги зображень
`assets/images/` — зображення та SVG-ілюстрації
`*.html` у корені — сторінки сайту
`sw.js`, `cache-init.js` — service worker та його реєстрація
`firestore.rules` — правила безпеки Firestore для мануального розгортання
